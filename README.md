# Pragyan AI Website

Static Vercel-ready website.

## Deploy
1. Push this folder to GitHub.
2. Vercel automatically redeploys from `main` once the Git repo is connected.
3. Framework preset: **Other**. No build command required.

## Notes
- The homepage uses the supplied Pragyan eye artwork directly at `assets/pragyan-eye.png`.
- The navigation logo is extracted from the same supplied eye artwork.
- Contact form is visual only until connected to a backend/form service.
- Insight article feed is currently static placeholder content.
